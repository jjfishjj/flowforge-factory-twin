# LinkedIn post

## English

I built **FlowForge Factory Twin**, a browser-based digital factory portfolio project designed around OpenUSD and NVIDIA Omniverse workflows.

The demo connects facility-layout decisions to measurable operating outcomes:

- Baseline vs. optimized U-cell layout
- Capacity, WIP and bottleneck simulation
- Animated robot arm, conveyor, AGVs and material flow
- AGV utilization, blocked time, queue heatmap and conflict-event analysis
- OpenUSD variants, references, payloads and factory/MES metadata

In the modeled scenario, the optimized layout reduces material travel from **86 m to 52 m per unit — a 40% reduction**.

The Web Demo runs without Composer, while the authored USDA stage and Kit Extension remain ready for validation on a Windows RTX workstation.

Live demo: https://jjfishjj.github.io/flowforge-factory-twin/
